# A Little Message for You 💗

A small pink-and-purple confession website made with HTML, CSS, and JavaScript.

## Files
- `index.html` — welcome page and first two choices
- `confirm.html` — playful confirmation page
- `confession.html` — full message and your name
- `style.css` — design, colors, animations, and responsive layout
- `script.js` — playful button interaction

## Test locally
Open `index.html` in a browser. Keep all files in the same folder.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload all five files into the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish, then open the URL shown on the Pages settings screen.

The public link usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize
Edit the text in `index.html` and `confession.html` if you want to make the message more personal. The website uses Google Fonts when online; fallback fonts are included.
